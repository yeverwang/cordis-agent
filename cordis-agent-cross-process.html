01

同一语义 · 两种物理层

scope tree ↔ process tree
layer   A

进程内 · scope tree

SML 运行时内的引用图；dispose 是函数调用。
+释放 = 纯函数递归
+纳秒级 · 无 IPC
+类型系统兜底不变式
✕SML 崩溃 = 全树蒸发
✕无法承载真实工作负载的隔离
layer   B

跨进程 · process tree

OS 内核维护的进程组；dispose 是发信号。
+释放 = kill(-pgid, SIGTERM)
+崩溃隔离 · 单进程 OOM 不牵动兄弟
+内核 PR_SET_PDEATHSIG 兜底孤儿
↳成本：fork/exec ≈ 数毫秒
↳需 wait() 收尸避免僵尸
02

SIGTERM 传播时线 · 从父进程到叶子

grace period → SIGKILL
fig. process group signal cascade
t+0

trigger

kubectl delete / systemctl stop / 用户 Ctrl-C 触发 kill(pid, SIGTERM)。

+10ms

handler intercepts

Cordis root 注册的 Signal.setHandler SIGTERM 触发；进入 dispose 流程。

+50ms

broadcast to pgid

root 调用 kill(-pgid, SIGTERM)——一个系统调用把信号广播给整个进程组。

+2s

graceful drain

各 agent 关闭日志、flush 数据、断开 socket；disposer 逆序释放外部资源。

+3s

reap children

root 在 waitpid 循环里逐个收尸；SIGCHLD 触发的僵尸进程被 WNOHANG 清空。

+10s

hard kill

还没退出的子进程收到 SIGKILL——不可屏蔽，内核直接回收；PR_SET_PDEATHSIG 兜底孤儿。

03

四种失败姿势 · 与它们的兜底

crash · orphan · zombie · partition
A · orphan

父进程 OOM 突死

父进程被 OOM killer SIGKILL——信号处理器根本没机会跑， dispose 流程未启动，子进程被内核 reparent 到 init。

Fix. 子进程 fork 后立即 prctl(PR_SET_PDEATHSIG, SIGTERM)—— 内核在父死那一刻发信号给子，父任何死法都兜住。
B · hang

子进程忽略 SIGTERM

业务代码卡在阻塞 IO 或死循环，SIGTERM 排队等到解阻塞—— grace period 期间不会退。

Fix. 内核 grace timer 到期后 kill(-pgid, SIGKILL)——SIGKILL 不可屏蔽， 内核绕过用户态直接回收；有代价：数据未 flush。
C · zombie

已死但未 waitpid

子进程已 exit，内核保留 PID + 退出状态直到父 wait； 长期不 wait → PID 表泄漏 → 系统 fork 失败。

Fix. root 循环 waitpid(-1, WNOHANG)；或让子进程被 init reparent （subreaper），init 自动收尸。
D · distributed

跨节点父子失联

Agent supervisor 在 A 节点，worker 在 B 节点； A 与 B 之间网络分区，SIGTERM 送不过去。

Fix. 换成 lease + heartbeat——worker 定期续约， 超时未续则自杀。信号语义在分布式下退化为超时协议。

Poly/ML 的 Posix 桥接 · 落到源码

Posix.Process · setpgid · kill
FORK & SETPGID
(* fork a child into its own supervised group *)
fun forkSupervised (name, exec) =
  case Posix.Process.fork () of
    NONE =>    (* CHILD *)
      ( Posix.ProcEnv.setpgid
          { pid = NONE, pgid = NONE }
      ; parent death fires SIGTERM *)
      ; Posix.Process.exec
          (exec, ["", name]) )
  | SOME pid => (* PARENT *)
      ( Posix.ProcEnv.setpgid
          { pid = SOME pid,
            pgid = SOME (Posix.Process.getpid ()) }
      ; recordChild (name, pid) )
SIGTERM HANDLER & REAP
(* on parent's SIGTERM: broadcast to group, wait *)
fun installShutdown () =
  Signals.setHandler
    (Signals.sigTerm,
     Signals.HANDLER
       (fn _ =>
          ( Posix.Process.kill
              (Posix.Process.K_GROUP
                 (Posix.Process.getpid ()),
               Posix.Signal.term)
          ; reapAll ()
          ; Signals.default )))

and reapAll () =
  case Posix.Process.waitpid_nh
          (Posix.Process.W_ANY_CHILD, [])
    of NONE => ()
     | SOME _ => reapAll ()
SYSCALL CHEATSHEET · POSIX ↔ POLY/ML
fork(2)

Posix.Process.fork : unit → pid option  ·  NONE = 子进程，SOME pid = 父进程

setpgid(2)

Posix.ProcEnv.setpgid  ·  建立独立进程组，让 kill(-pgid, ...) 一击广播

kill(-pgid, sig)

Posix.Process.kill (K_GROUP pgid, sig)  ·  一次系统调用发信号给整组

waitpid(2)

Posix.Process.waitpid_nh  ·  WNOHANG 非阻塞收尸；避免僵尸

prctl(PDEATHSIG)

Poly/ML 无原生绑定 → 用 Foreign 桥接 libc  ·  父死即子死
